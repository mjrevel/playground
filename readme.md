# Playground
This project contains multiple mini-demos featuring various Godot elements. Most of these demos are derived from various tutorials (such as the godot-demo-projects).

Not all of the demos directly run out of the box. For example: The shader demos only have one scene file and require that the shader code be dropped and tweaked in the ShaderMaterial node. I'll continue to clean this up if this provides to be a useful resource to those other than myself.
